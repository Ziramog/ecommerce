## 1. Resumen Ejecutivo

El ticket **M360-020** implementa el storefront e-commerce minorista B2C **Pampa Novus** dentro de `apps/pampa-novus`, materializando la experiencia visual de alta gama orientada a la talabartería tradicional argentina, aperos criollos, marroquinería y platería fina ("Lujo Criollo").

El storefront consume en tiempo real el catálogo maestro y los precios minoristas en pesos argentinos (ARS) desde la instancia Staging de Medusa 2 viva en el VPS (`http://100.124.132.48:9000`), sin alterar el inventario ni interferir con las reglas mayoristas privadas de Talabartería Mercadal (B2B).

## 2. Decisiones Arquitectónicas & Saneamiento Monorepo

### 2.1 Unificación y Deduplicación Estricta de React (18.3.1)
- **Problema Detectado**: Durante el prerendering de Next.js (`next build`), se originó el error de mismatch de símbolos `Minified React error #31` derivado de una resolución bifurcada: Next.js 15 resolvía react desde una copia anidada de React 19 en `apps/pampa-novus/node_modules`, mientras el monorepo y el backend Medusa estaban en React 18.3.1.
- **Solución Implementada**:
  1. Configuración de bloque de `overrides` en la raíz de `package.json`:
     ```json
     "overrides": {
       "react": "18.3.1",
       "react-dom": "18.3.1"
     }
     ```
  2. Saneamiento de `package-lock.json` eliminando las entradas huérfanas anidadas en `apps/pampa-novus/node_modules/`.
  3. Resultado: `npm list react react-dom` reporta 100% de árbol deduplicado sin advertencias ni conflictos.

### 2.2 Sistema de Diseño "Lujo Criollo"
Se definieron tokens semánticos en `tailwind.config.ts`:
- **`pampa`**: Escala de tonos tierra y pergamino neutro (`pampa-50` #FAF8F5 a `pampa-950` #1E1B18).
- **`leather`**: Matices de cuero curtido vegetal (`#8B4513` a `#5C2E0B`).
- **`alpaca`**: Tonos metálicos sutiles que evocan la platería criolla.
- **`brass`**: Acentos cálidos dorados para herrajes y pasadores.
- **Tipografía**: Combinación de `Playfair Display` (serif editorial para encabezados y titulares) e `Inter` (sans-serif para lectura clara de precios, especificaciones y navegación).
